# 🚀 解除网页复制限制 · Unblock Copy

> **装了这个脚本，全网内容随便复制。**  
> 不需要任何设置，安装即用。

---

## 🎯 这个脚本是干什么的？

有些网站不让你**选中文字**、**右键**、**复制**、**粘贴**，甚至按 Ctrl+C 都会弹窗拦你。

这个脚本一键解除所有限制，装完之后：

| 原来 | 现在 |
|---|---|
| ❌ 文字选不了 | ✅ 随便选，想选多少选多少 |
| ❌ 右键没反应 | ✅ 右键菜单正常弹出 |
| ❌ Ctrl+C 被拦截 | ✅ 正常复制 |
| ❌ 粘贴不让用 | ✅ 粘贴正常 |
| ❌ 弹窗让你登录才能复制 | ✅ 直接复制，不用登录 |

## ❓ 常见问题

### Q：装了之后所有网站都不能复制了？
**不会。** 脚本只解除限制，不影响正常网站的复制功能。正常网站该怎么用还怎么用。

### Q：会影响网页的其他功能吗？
**不影响。** 脚本只针对「禁止复制」「禁止选中」「禁止右键」「禁止粘贴」这四项做解除，不干别的事。

### Q：需要手动开启吗？
**不需要。** 安装即生效，每次打开网页自动运行。

### Q：这个脚本安全吗？
**100% 安全。** 脚本完全开源（代码在这里公开可见），不收集任何数据，不上传任何信息，只在你本机运行。

### Q：我想暂时关掉怎么办？
点击浏览器右上角的 Tampermonkey 图标 → 把「解除网页复制限制」的开关关掉即可。
